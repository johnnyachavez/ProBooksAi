Python + desktop (SQLite)

The repo has a CLI (python -m probooks) and a PySide6 desktop app (python -m desktop_app.main) on the same SQLite schema. What is implemented today is summarized under Implementation snapshot in docs/ROADMAP.md ; cross-phase items (#21, packaging, backup UI, theme, CI tests) are under Supporting / cross-cutting in the same file (static index.html is a dark UI shell only — not live books data). 

pip install -e ".[dev]"
python -m probooks migrate
python -m probooks status
python -m probooks accounts add --name "Checking" --type checking --last4 1234
python -m probooks accounts list
python -m probooks import csv -a 1 -f sample.csv --skip-rows 1 --date-col 0 --amount-col 1 --payee-col 2
python -m probooks transactions -a 1 -n 20

Desktop: pip install -e ".[desktop]" then python -m desktop_app.main — details in README.md (Desktop app). Default SQLite paths (two files, issue #21): README.md. --help on the CLI or desktop entrypoint prints the shared Excel workbook line from probooks/help_epilog.py (same README section). Excel COA template: README.md. Backup/restore and tests: same README; run python -m pytest.
